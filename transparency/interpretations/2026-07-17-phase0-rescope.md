# Phase 0 Rescope: Capture-Schema First, Attorney as Launch Gate, Interviews Deferred

**Date:** 2026-07-17

**Decision:** Three connected rescoping decisions for Roadmap Phase 0, made
together as one resourcing judgment:

1. **Locked Decision 16 amended — capture schema now, data table in Phase 1.**
   Phase 0 delivers the moderation-outcomes *capture schema* as a committed
   markdown specification (every field a moderation outcome must record).
   The physical data table and public read view move to Phase 1's initial
   schema pass, authored from that specification. Report generation follows
   the table.
2. **IP attorney engagement moves from "Phase 0, start early" to a Phase 5
   launch gate.** The platform will not launch with an unreviewed custom
   perpetual license. Standard instruments already adopted verbatim
   (AGPL-3.0-or-later, DCO) need no counsel. DMCA agent registration
   proceeds now (founder, no counsel required).
3. **User interviews deferred to early post-launch; founder journey-mapping
   substituted for Phase 0.** Interviews are deferred, not cancelled.

**Commitments implicated:**

- (1) Amendment of LD 16: Commitment 6 (Speak truth — the log). The
  principle "infrastructure precedes use" is preserved: the markdown
  convention already exists before any decision it must record, and no
  moderation *data* can exist before the platform does. Designing the
  capture schema now, the table at first possible use, honors the principle
  without building storage for data that cannot yet occur.
- (2) Attorney gate: Commitment 3 (What you create, you steward — and we
  will defend it). The perpetual license is the instrument by which member
  IP is protected on-platform; launching it on unreviewed AI-drafted text
  would strain the "we will defend it" clause. Gating launch on counsel
  review is the covenant-honoring form of the resource constraint.
- (3) Interview deferral: Commitment 8 (We are here to serve) is **strained,
  and the strain is accepted knowingly**: founder-imagined journeys are not
  direct contact with the people Open Eppic serves. Mitigations: the founder
  is a genuine first user of the platform's type; user-research
  participation is already a ledger-recognized contribution (Locked Decision
  18), making early members the interview pool immediately post-launch.

**Conflict rules applied:** Rule 1 (examine assumptions) for the LD 16
amendment — the apparent conflict between "infrastructure precedes use" and
"don't build ahead of reality" dissolves once *use* is dated correctly.
None for the other two — direct application.

**Options considered:**

- **Build the moderation table now anyway — strains build quality.** A table
  designed with zero real-world contact and no possible data invites rework;
  the capture schema preserves the design decision without freezing the DDL.
- **Launch with AI-drafted perpetual license, no counsel — violates
  Commitment 3 in spirit.** Rejected. AI legal drafting (including installed
  legal plugins) is preparation and risk-flagging, not counsel: no
  privilege, no jurisdictional sign-off, no accountability.
- **Cancel interviews outright — violates Commitment 8.** Rejected;
  deferral with a named return point instead.

**Decided by:** Founder, with advisory assessment.

**Consequences accepted:** Phase 1's schema pass grows by one migration.
Launch timing becomes dependent on funding counsel review. Pre-launch design
carries founder-bias risk until post-launch interviews correct it.
